# Инвайт подписчиков из чата-донора: новички чужого чата переходят в ваш

Инвайт подписчиков из чата-донора - это режим, в котором аккаунт сидит в чужой тематической группе и приглашает в ваш чат каждого, кто туда только что вступил. Готовый список людей не нужен: источником служит сам поток новичков. В **AlexSoftClub** это режим "Инвайт новых подписчиков из чата-донора" задачи **17 Инвайтер**, и приглашение идёт по ID - самым бережным для аккаунта способом.

## Как это работает

1. Каждый аккаунт получает свой чат-донор из таблицы `04 1`. Целевой чат берётся из `17 2`. При необходимости аккаунт вступает в оба.
2. Аккаунт ждёт событий вступления в доноре. Каждый новичок записывается в `17 1` с отметкой 🟡 и встаёт в очередь.
3. Через случайную задержку из настроек аккаунт приглашает новичка в ваш чат. Результат пишется в `17 4`, а строка в `17 1` меняет отметку на 🟢 или 🔴.
4. Работа бессрочная: аккаунты сидят в донорах, пока вы не остановите задачу кнопкой остановки (в консольном режиме - ввести `0` и нажать ENTER).

Ключ доступа к новичку Telegram отдаёт вместе с самим событием вступления, поэтому резолв юзернейма не нужен и подготовка через парсер, как у [инвайта по ID](https://github.com/alexsoftclub/invayt-po-id), тоже не требуется.

## Возможности

- **Без базы людей.** Не нужно заранее парсить аудиторию: в ваш чат попадают свежие, только что заинтересовавшиеся темой люди.
- **Один донор - один аккаунт.** Второй аккаунт в уже занятый донор не пойдёт.
- **Очередь не теряется.** Если новичков больше, чем аккаунт может безопасно позвать, они ждут. Не приглашённые за запуск остаются в `17 1` свободными строками, и их можно позвать обычным [инвайтингом в Telegram](https://github.com/alexsoftclub/invayting-telegram) - ключи доступа сохранены.
- **Фильтр по юзернейму.** Можно звать только людей с юзернеймом или всех подряд.
- **Понятный лог:** в каком доноре сидит аккаунт, кого поймал, через сколько секунд инвайт и сколько человек в очереди.

## Настройки

| Настройка | Рекомендация |
|-----------|--------------|
| Задержка перед инвайтом новичка (сек) | `120-600`, разброс обязателен: мгновенный инвайт выглядит как бот |
| Инвайтов в час на аккаунт (0 - без ограничения) | `4-6` |
| Инвайтов в сутки на аккаунт (0 - без ограничения) | `40` |
| Пропускать новичков без юзернейма (1 - Да / 2 - Нет) | `2` - инвайт по ID юзернейма не требует |
| Кол-во одновременно работающих потоков | по числу аккаунтов |

Суточный лимит считается по `17 4` и переживает перезапуск.

## Лимиты Telegram и ограничения режима

- Работает только с группами и супергруппами: в каналах Telegram не отдаёт события вступления. Ваш целевой чат тоже должен быть группой.
- Аккаунт должен реально состоять в доноре. В чате с заявками на вступление задача ждёт, пока администратор одобрит заявку.
- Ссылок на доноров в `04 1` должно быть не меньше, чем аккаунтов. Аккаунт без донора завершится со статусом "нет свободного чата-донора".
- Общая безопасная норма - около 40-50 приглашений в день на аккаунт.

## Как запустить

1. В SQLiteStudio впишите ссылки на чаты-доноры в `04 1 Парсер пользователей ссылки`, а ссылку на свой чат - в `17 2 Инвайтер ссылки на группы`. Таблицы `17 1` и `17 4` заполнит программа.
2. В главном меню мышкой кликните **17 Инвайтер**.
3. В подменю выберите **Инвайт новых подписчиков из чата-донора**.
4. Проверьте настройки и нажмите **"Продолжить"**.
5. Введите задержку старта и нажмите **"Запустить"**. Остановить можно в любой момент.

## Частые вопросы

### Как приглашать в свой чат новых участников чужой группы?
Включите в AlexSoftClub режим "Инвайт новых подписчиков из чата-донора". Аккаунт вступает в чужую группу, отслеживает новичков и через случайную задержку зовёт каждого в ваш чат. Готовый список людей не нужен.

### Можно ли использовать канал как донор?
Нет. О вступлении в канал Telegram события не присылает, поэтому донором может быть только группа или супергруппа.

### Сколько новичков в день пригласит один аккаунт?
Сколько разрешают настройки: рекомендовано 4-6 в час и 40 в сутки. Остальные ждут в очереди и не теряются.

### Нужен ли юзернейм у новичка?
Нет. Приглашение идёт по ID, ключ доступа приходит вместе с событием вступления. Если хотите звать только людей с юзернеймом, поставьте "Пропускать новичков без юзернейма" = `1`.
